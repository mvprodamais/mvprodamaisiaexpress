📋 RESUMO DO PROJETO
═══════════════════════════════════════════════════════════════════════════

Este é um MVP (Mínimo Produto Viável) de um bot de WhatsApp para consulta e
pré-reserva de passagens de ônibus. O bot funciona 100% dentro do WhatsApp,
sem necessidade de site ou aplicativo adicional.

🎯 FUNCIONALIDADES PRINCIPAIS
═══════════════════════════════════════════════════════════════════════════

✅ Fluxo Conversacional Completo
   - Menu inicial com 2 opções
   - Seleção de origem (3 cidades)
   - Seleção de destino (3 cidades)
   - Tipo de viagem (ida ou ida e volta)
   - Data de viagem (formato DD/MM)
   - Período (manhã/tarde/noite)
   - Número de assentos (1-5)
   - Tipo de poltrona (convencional/semi-leito/leito)

✅ Busca de Viagens
   - Exibição de 3 opções de viagem
   - Horários, preços e viações
   - Filtragem por período

✅ Pré-Reserva
   - Código numérico (4 dígitos)
   - Código alfanumérico (RM-XXXXXXXX)
   - QR Code em PNG
   - Validade de 10 minutos

✅ Integração WHAPI
   - Recebimento de mensagens via webhook
   - Envio de mensagens de texto
   - Envio de imagens (QR Code)

✅ Gerenciamento de Sessão
   - Controle por número de telefone
   - Sessões em memória
   - Timeout de 30 minutos

🚀 COMO FAZER DEPLOY
═══════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Railway (Recomendado)
────────────────────────────────

1. Criar repositório GitHub
   git init
   git add .
   git commit -m "WhatsApp Bus Booking Bot"
   git remote add origin https://github.com/seu-usuario/whatsapp-bus-booking
   git push -u origin main

2. Acessar https://railway.app
3. Clicar "New Project" → "Deploy from GitHub"
4. Selecionar repositório
5. Clicar "Deploy Now"
6. Aguardar 2-3 minutos

7. Configurar variáveis:
   - WHAPI_TOKEN: 0W3kwqeFeP6DLgMA5ASn0T2Wvs7xj3u4
   - NODE_ENV: production

8. Copiar URL pública (ex: https://seu-projeto.railway.app)

OPÇÃO 2: Render
────────────────

1. Preparar repositório GitHub (mesmos passos acima)
2. Acessar https://render.com
3. Clicar "New Web Service"
4. Conectar GitHub
5. Preencher:
   - Name: whatsapp-bus-booking
   - Build Command: npm install
   - Start Command: node server.js
6. Configurar variáveis de ambiente
7. Deploy automático

OPÇÃO 3: Fly.io
────────────────

1. Instalar CLI: curl -L https://fly.io/install.sh | sh
2. Login: flyctl auth login
3. Deploy: flyctl launch
4. Configurar secrets: flyctl secrets set WHAPI_TOKEN="..."
5. Deploy: flyctl deploy

🔧 CONFIGURAR WEBHOOK NO WHAPI
═══════════════════════════════════════════════════════════════════════════

1. Acessar https://whapi.cloud
2. Ir para Webhooks
3. Adicionar webhook:
   - URL: https://seu-dominio.com/whapi/webhook
   - Events: messages
4. Salvar

5. Conectar número de WhatsApp Business
6. Testar webhook

📱 TESTAR BOT

2. Enviar mensagem para seu número
3. Bot responde com menu
